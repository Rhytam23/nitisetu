# Niti-Setu — User & Admin Workflow Specifications

---

## 1. Complete Farmer Workflow
`Register / Login` → `Farmer Dashboard` → `Evaluate Scheme` → `Proof Card & Verbatim Citation` → `Upload Land Record to Vault` → `Cloud Vision OCR` → `Farmer Confirmation` → `Profile Mismatch Alert Sync` → `Logout`

---

## 2. Complete Admin Workflow
`Admin Login` → `Admin Dashboard` → `Platform Analytics` → `Farmer List (PII Masked)` → `Scheme RAG Status` → `Document OCR Queue` → `Audit Trail Logs` → `Logout`
